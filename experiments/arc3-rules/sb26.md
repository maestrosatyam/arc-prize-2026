## Core rules

- Background colour 4. The top strip shows the target sequence: 6x6 outlined boxes in target colours on colour-5 tiles, ordered by row then column; L8 has two rows (12 targets) [L211-223, L262-266, L719-720; sb26.core.c1; engine E19].
- Frames: bordered boxes with 1-7 slots (the slot count is the last digit of the frame sprite name; slot i sits at frame x+2+6i, y+2). The default border colour is 8; other frames are recoloured. The top-most (then left-most) frame is the main program; all other frames are subroutines identified by border colour [L31-66, L125-141, L159-175, L193-209, L713-714, L976-987; sb26.core.c2; engine E20].
- Empty slot: 6x6 cell showing a 2x2 colour-2 dot. Item: 6x6 cell with a solid 4x4 square of its colour. Items in the inventory row (below the HUD line, y>53) are clickable and an empty slot is created under each, so moving an item out leaves a slot to move items back into; items pre-placed inside frames lose the click tag and are fixed [L90-103, L225-238, L708-716, L886; sb26.core.c3; source-only].
- Call item: 6x6 cell with a hollow 4x4 square of colour c. When executed it runs the frame whose border colour is c from its first slot, then returns to the slot after the call; calls nest, and a frame can call itself [L267-280, L912-939, L953-967; sb26.core.c4; engine E21].
- Click (ACTION6): with nothing selected, clicking a clickable item selects it (black outline). With an item selected: clicking it again deselects; clicking another inventory item while the selected item is also in the inventory moves the selection; clicking any other clickable item swaps the two positions; clicking an empty slot moves the item there and reopens its old slot. Each completed move or swap costs 1 energy and is pushed to the undo history [L1020-1050, L884-891; sb26.core.c5; engine E22].
- Run (ACTION5): 1 energy. A cursor walks the main frame left to right while a second cursor walks the targets. A solid item must equal the colour of the current target; on match the target fills with that colour and both cursors advance; on mismatch the run fails: cursors flash colour 8, all target fills are cleared, item placements stay [L866-878, L893-903, L912-923, L971-974, L800-816; sb26.core.c6; engine E23].
- A run also fails when it reaches an empty slot, or when the main frame is exhausted with targets left (the unfilled targets are outlined in colour 8). Once the last target is filled the level is cleared; slots after that point are not executed [L904-911, L939-952, L968-969; sb26.core.c7; engine E24 for the empty-slot case, source-only for the rest].
- Undo (ACTION7) restores the positions and visibility of items and slots to before the last move or swap; energy is not refunded; no effect when there is no history [L1052-1066; sb26.core.c8; engine E25, control E26 (sb26.core.c12)].
- Energy: 64 per level, reset on each level start. HUD row 53: colour 2 for the remaining fraction, colour 3 for the used part. Energy 0 at the end of a move animation or a failed run gives GAME_OVER [L679-687, L700-702, L800-816, L854-866; sb26.core.c9; engine E27, E28 (sb26.core.c13), E29 (sb26.core.c14)].
- Recursion guard: a call item in slot 0 of a frame that is already running from its own slot 0 fails the run [L953-956; sb26.core.c10; source-only].
- No randomness; the layout is fixed per level [L339-664; sb26.core.c11; source-only].
