## Core rules

- Two panels. Right panel: a board with the piece (4x4, colour 11, a two-pixel notch on one side shows rotation), a target outline (colour 11 U-shape), optional walls, checkpoints and beams, an editable program (a row of columns of bit cells) and a round run button. Left panel (L2-L7): the same layout with a colour-4 piece and a read-only program, used only for demonstrations; L1 has the right panel only [L2452-2476, L2136-2148, L9-21, L886-900; tn36.core.c2; engine].
- Program encoding: the program is a sequence of rows (drawn as vertical strips, left to right); each row's value is the sum of 2^i over its lit cells, i counted from the top; lit cells are colour 5, unlit colour 1; clicking a cell toggles it; the left program cannot be edited [L1913-1927, L1933-1934, L1987-2018; tn36.core.c2; engine].
- Opcodes: 0 no-op; 1 and 34 left 4; 2 right 4; 3 down 4; 33 up 4; 10/11 right 8; 12/13 left 8; 5 rotate +90; 6 rotate -90; 7 rotate 180; 16 rotate 270; 8 scale +1; 9 scale -1; 14 colour 9; 15 colour 8; 63 colour 15; every other value is a no-op [L2149-2169; tn36.core.c3; engine].
- Run: rows execute top to bottom, one per frame, on the right piece; a move or scale change that overlaps a wall (colour 6) is undone [L2247-2273, L2336-2385; tn36.core.c4; engine]. 8-px moves test only the destination and so jump a 4-px wall [L2160-2163, L2247-2259; tn36.core.c10; engine].
- Win: after a run, the right piece equals the target in position, scale, rotation and colour; the level then advances [L2131-2134, L2366-2373, L2606-2609; tn36.core.c5; engine].
- Failed run: the piece returns to its start state; if it ended on a checkerboard checkpoint (colour 11, same scale) that position/state becomes the new start; program bits are kept between runs [L2286-2309, L2353-2365; tn36.core.c6; engine].
- Tabs: a tab loads its fixed demonstration program with its start position, rotation and scale into the left panel and runs it; the left piece is not reset afterwards; the right panel is unaffected [L2478-2521, L1147-1151 etc.; tn36.core.c7; engine].
- Timer: the colour-9 bar on row 1 shifts one cell left per click (every second click from L6 on); when used up the game is lost: 61 clicks in L1-L5, 122 in L6-L7 [L2550-2570, L2602-2613, L2618-2619; tn36.core.c8, tn36.L6.k3; engine].
- Beams (striped colours 12/13 with a colour-14 emitter end): they toggle visibility after the third executed row of a run (if rows follow) and after every failed run; they start hidden. A piece overlapping a visible beam or an emitter is broken and cannot move for the rest of the run [L2328-2334, L2361-2362, L1872-1881, L2045-2056, L348-371; tn36.core.c9; engine].
- No randomness [L2573-2625; tn36.core.c11; source-only].
