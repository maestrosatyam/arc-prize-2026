## Core rules

- Tiles (tag Hkx, plain squares): all start in the first colour of the level's colour list (cwU) [L2306-2320]. Clicking a plain tile advances that tile only to the next colour in the list, cyclically [L2385-2402] [L2306-2320, L2385-2402; ft09.core.c1; engine E1, E12].
- Pattern tiles (tag NTi, L5-L6): a tile showing colour-6 marks in some of its 8 border cells. Clicking it advances itself and every neighbour tile (4 px away) in the marked directions [L2322-2326, L2378-2402] [L2322-2326, L2378-2402; ft09.core.c2; engine E10, E11]. Their own colour changes only when they are clicked or hit by another pattern tile.
- Clue tiles (tag bsT, fixed): centre colour c and 8 border marks. Mark 0 (black): the neighbour tile in that direction must be colour c. Any other mark (2 red, 3 green): the neighbour must not be colour c. Positions without a tile are not checked (colour-3 marks sit where there is no tile) [L2414-2498] [L2414-2498; ft09.core.c4; engine E1, E13].
- Win: after every tile click, the level is cleared when every clue is satisfied [L2404-2407] [L2404-2407; ft09.core.c5; engine E1-E6].
- Budget per level (kCv): 32, 32, 96, 96, 128, 128 tile clicks [L2042, L2071, L2111, L2147, L2198, L2238]. HUD: bottom row y=63, colour 12 for the remaining fraction, 11 for the used part [L2267-2276]. The click that uses the last unit ends the game (GAME_OVER) unless it wins [L2409-2410] [L2042, L2071, L2111, L2147, L2198, L2238, L2267-2276, L2409-2410; ft09.core.c6; engine E8].
- Colour swatches at the top right (L2-L6) show the level's colour cycle in order [L2066-2067, L2082, L2121-2142, L2193, L2208-2212] [L2066-2067, L2082, L2121-2142, L2193, L2208-2212; ft09.core.c7; source-only].
- L1 only: a frame around the puzzle flashes when the player clicks outside any tile [L2297-2300, L2333-2341, L2364-2368] [L2297-2300, L2333-2341, L2364-2368; ft09.core.c8; engine E14].
- No randomness [whole file; ft09.core.c9; source-only].
