## 2. Noise: is any run different from the others beyond pass-to-pass variation?

Each pass is an independent replicate of all 25 games, so every run gives four replicate means. Pooled within-run SD of a pass mean: **4.91**; expected SD of a 4-pass run mean if all runs were identical: **2.46**; observed SD of the 6 run means: **2.21**. One-way ANOVA on the 24 pass means: F = 0.81 with (5, 18) degrees of freedom (the 5% critical value is 2.77).

## I5a-16 (memory-only variant, reduced screen)

Run: 16 games x 3 passes, 3 h 56 m, 48 game-passes, 9 won. Mean 40.48 vs P0 50.75 on the same 16 games (paired diff -10.27, permutation p 0.063). The nine always-low or always-high games were excluded by design, so this is a screen, not a 25-game estimate. Largest per-game drops: vc33 -59.0 (levels 6.0/7 -> 3.0), cd82 -30.8, sp80 -27.4, cn04 -26.1; gains: tr87 +14.1, tu93 +7.9, ls20 +5.3. Together with I5 (-3.27 on 25 games) the memory family has two negative readings and no positive one.
